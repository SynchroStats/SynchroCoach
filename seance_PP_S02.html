A1
Planche + balle de tennis
Anti-rotation
En cercle, position planche. Se passer la balle en croisant.
→ NOUVEAU : plot posé dans le bas du dos avant de commencer. Si le plot tombe = bassin qui s'effondre. Consigne avant chaque 30'' : "bassin horizontal, plot en place, ensuite on passe la balle."
→ Observer : qui perd le plot dès la première passe vs qui maintient. Feedback individuel en passant.
A2
Unipodal + medicine ball
Équilibre + double tâche
En cercle sur 1 pied. Se passer le medball. Alterner la jambe d'appui entre les 30''.
→ NOUVEAU : augmenter la distance entre filles + passes en cloche (trajectoire haute) — le temps de vol plus long force une déstabilisation plus longue à gérer.
→ Si trop facile même avec la distance : ajouter les yeux fermés à la réception.
A3
Arabesque en ligne + passage sous la jambe
Stabilité + synchronisation
En ligne, arabesque tenue. La voisine passe sous la jambe simultanément.
→ Elles connaissent cet atelier — hausser l'exigence : arabesque plus haute, passage plus coordonné.
→ Seul : bout de ligne pour voir toute la rangée.
~32 min
Circuit — PAP intégré
5 stations · 4 tours · 40s/20s · Pause 2 min inter-tour
▼
⏱ 40s travail / 20s rotation
🔄 4 tours = 26 min
☕ Pause 2 min entre tours
⚡ S3→S4 enchaînement PAP
Amorce : 1 groupe commence sur S3 (squats élastique) pendant que les autres s'installent. Ensuite tout le monde tourne normalement. Comme ça chaque groupe passe systématiquement par S3 juste avant S4.
S1
Step touch latéral rapide 4m D/G
Aérobie + coordination
Déplacement latéral rapide sur 4m, pas chassés, bras actifs. Maintenir le rythme sur les 40 sec.
✓ Proche de la gestuelle glace — faire le lien verbalement.
S2
TRX Row incliné / Pompes bras surélevés
Force haut du corps
Avec TRX : tirade en rangée, corps incliné. Plus horizontal = plus difficile.
Sans TRX : pompes bras surélevés sur banc.
→ Point faible majeur S01. Observer la progression — est-ce qu'elles gèrent mieux qu'en S01 ?
✓ Qualité d'exécution avant le nombre de reps.
S3
Squats élastique — activation fessier moyen
NOUVEAU · PAP
Élastique autour des genoux. Squat profond, genoux qui poussent activement sur l'élastique — ne pas laisser les genoux rentrer vers l'intérieur. Tempo lent et contrôlé, pas de vitesse.
→ OBJECTIF : activer le fessier moyen dans la fenêtre PAP (3–8 min) avant S4. Pas un exercice de cardio — un exercice d'activation.
👁 Corriger immédiatement le valgus. C'est exactement l'erreur observée en S01 sur les box jumps.
✓ ~10–12 reps propres > 20 reps en valgus.
⚡ PAP — S3 nourrit S4 ⚡
S4
Box Jump coordonné à 2 — unipodal
Explosivité · Reçoit PAP
Binômes sur boxes. Saut unilatéral coordonné — partir et atterrir ensemble. Progression si réception propre.
→ OBJECTIF S02 : observer si le valgus à la réception est réduit grâce à S3. C'est le test de l'effet PAP.
👁 Réception genou dans l'axe — corriger immédiatement le valgus résiduel.
✓ Novices : step-up unilatéral propre avant de sauter.
S5
Squat profond → saut → atterrissage unipodal
Puissance + stabilité
Squat profond → impulsion maximale → atterrissage 1 pied → tenir 2 sec immobile. Alterner le pied d'atterrissage.
→ NOUVEAU : pause 2 sec obligatoire à l'atterrissage annoncée avant le tour. "On ne repart pas avant d'être stable."
✓ Observer asymétrie D/G — info pour les tests formels.
👁 Toujours le tirage par la nuque ? → rappel : l'impulsion vient des jambes, les bras accompagnent.

1 sifflet = rotation. 2 sifflets = pause inter-tour.
Groupes de 3–4 par station. Toutes tournent dans le même sens.
